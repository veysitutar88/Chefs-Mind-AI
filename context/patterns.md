# Project Patterns

## Documentation
- **Source of Truth:** `MASTER_CONTEXT_v2.1.6.mdown` is the primary reference.
- **Manifest:** `MASTER_MANIFEST.json` tracks all critical files.
- **Archiving:** Old files are moved to `docs/archive/` instead of deletion.

## Development
- **Blocks:** Development is organized into Blocks (0-5).
- **Agents:** 5 distinct agents (Chef, Accountant, Researcher, Media, QA) managed by an Orchestrator.
