# Chef's Mind AI - Memory Bank

## Общая структура проекта

Chef's Mind AI - это многоагентная система искусственного интеллекта, предназначенная для управления рестораном. Проект организован следующим образом:

```
c:/Projects/Chefs-Mind-AI/
├── server/                 # Серверные компоненты
│   ├── services/          # Сервисы для различных провайдеров ИИ
│   ├── routes/            # Маршруты API
│   ├── middleware/        # Промежуточное ПО
│   ├── graph/             # Графовые структуры агентов
│   └── utils/             # Вспомогательные утилиты
├── frontend-enhanced/     # Основной фронтенд
├── frontend-simple/       # Упрощенный фронтенд
├── logs/                  # Логи и отчеты
├── checkpoints/           # Чекпоинты проекта
├── .kilocode/             # Конфигурации KiloCode
└── shared/                # Общие типы и утилиты
```

## Активные модели и сервисы

### Модели ИИ

1. **OpenAI GPT-5** (основная модель для текстовых задач)
   - Используется для генерации текста, анализа и кулинарных рекомендаций
   - Настроена в `server/services/openai.ts`

2. **DALL-E 3** (генерация изображений)
   - Используется для создания визуального контента
   - Интегрирована в `server/services/openai.ts`

3. **Whisper** (распознавание речи)
   - Обрабатывает аудио вход для голосовых команд
   - Реализовано в `server/services/stt.ts`

4. **Google Models** (интеграция с Google)
   - Используются для работы с документами и таблицами Google
   - Реализовано в `server/services/google-mcp.ts`

### Агенты

1. **Chef Agent** - кулинарный эксперт
2. **Accountant Agent** - финансовый аналитик
3. **Research Agent** - исследователь и аналитик данных
4. **Media Agent** - создатель мультимедийного контента
5. **Universal Agent** - универсальный помощник
