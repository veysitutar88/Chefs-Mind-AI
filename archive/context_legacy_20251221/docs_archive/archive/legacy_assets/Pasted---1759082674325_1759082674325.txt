### **Финальное Техническое Задание: "Chef’s Mind AI"**

#### **1. Общая Концепция и Брендинг**
* **Название проекта:** **"Chef’s Mind AI"**. Это название должно использоваться во всем интерфейсе и коде.
* **Логотип:** Использовать **только тот файл логотипа, который был предоставлен** (`logo (2).png`). Он должен быть интегрирован в интерфейс на странице входа и в шапке приложения. Никакие другие или стандартные логотипы использоваться не должны.

#### **2. Аутентификация и Безопасность**
* **Система входа:** Реализовать независимую систему аутентификации **только по паролю с использованием JWT-токенов**.
* **Безопасность Базы Данных:** Настроить PostgreSQL с **двумя пользователями**:
    * `app_writer`: стандартный пользователь приложения с правами на чтение и запись (R/W).
    * `llm_reader`: отдельный пользователь **только для чтения (READ-ONLY)**, который будет использоваться для выполнения всех SQL-запросов, сгенерированных ИИ.
* **Валидатор SQL:** Реализовать на бэкенде обязательный валидатор для всех генерируемых ИИ SQL-запросов, который обеспечивает:
    * Разрешение **только `SELECT`**-операторов.
    * Блокировку DDL/DML команд (`INSERT`, `UPDATE`, `DROP` и т.д.).
    * Запрет на использование точки с запятой (`;`).
    * Автоматическое добавление `LIMIT` к каждому запросу.

#### **3. Архитектура: Интерфейс и Агенты**
* **Универсальный чат:** Реализовать основной чат-интерфейс с **политикой автоматической маршрутизации** запросов (без ручного переключателя моделей):
    * **Google Gemini 2.5 Pro:** используется для аналитики, генерации SQL и вывода структурированных данных.
    * **OpenAI GPT-5:** используется для форматирования текста в повествовательном стиле, объяснений и творческих текстовых задач.
* **Специализированные агенты:** В боковой панели предоставить доступ к **пяти** специализированным агентам:
    1.  **'Accountant' (Учетчик)**
    2.  **'Chef' (Шеф)**
    3.  **'Analyst' (Аналитик)**
    4.  **'Visualizer' (Визуализатор)**
    5.  **'Media Studio' (Медиа-студия)**

#### **4. Функционал Ключевых Модулей**
* **Media Studio:** Реализовать в агенте **переключатель типа контента**, позволяющий создавать:
    * **Изображения:** с выбором моделей **Imagen 3** и **DALL·E 3**.
    * **Видео:** с использованием модели **Veo 3**.
* **Импорт файлов:** Реализовать как первоклассную функцию возможность импорта файлов **CSV/XLSX** с прямой записью данных в PostgreSQL.
* **Вывод данных "Accountant":** Агент "Accountant" должен возвращать ответы в виде структурированных таблиц и предоставлять вывод `debug.sql` для проверки сгенерированного запроса.

#### **5. Технологический Стек и Локализация**
* **Интерфейс:** Реализовать на **React** с использованием **Tailwind CSS** и компонентов **shadcn/ui**.
* **Локализация:**
    * Язык интерфейса по умолчанию — **Русский (RU)**.
    * Язык генерируемого контента по умолчанию — **Немецкий (DE)**.
* **База данных:** Использовать **внешний** сервер **PostgreSQL**.

#### **6. Переменные Окружения (Secrets)**
Проект должен использовать следующие переменные окружения:
* `OPENAI_API_KEY`
* `GOOGLE_API_KEY`
* `PPLX_API_KEY`
* `DATABASE_URL` (для `app_writer`)
* `DATABASE_READONLY_URL` (для `llm_reader`)
* `JWT_SECRET`
* `ADMIN_PASSWORD`

#### **7. Критерии Приемки**
1.  Аутентификация по паролю работает корректно.
2.  Импорт CSV-файла успешно записывает данные в PostgreSQL.
3.  Запрос к агенту "Accountant" возвращает ответ в виде таблицы и отладочный SQL-запрос.
4.  Запрос к агенту "Visualizer" отрисовывает график в интерфейсе.
5.  Попытка выполнить SQL-запрос на запись или изменение данных (DDL/DML) через LLM отклоняется с ошибкой 400.
