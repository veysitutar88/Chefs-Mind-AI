# Instructions

## General Rules
1. Always refer to `MASTER_MANIFEST.json` as the single source of truth.
2. Do not modify code in `server/*` or `frontend-enhanced/*` without explicit command.
3. Update `SESSION.md` and `CHECKPOINT.json` at the end of each session.

## Workflow
- Start by loading the context workflow.
- Check `context/current-task.md` for active tasks.
- Log decisions in `context/decisions.md`.
