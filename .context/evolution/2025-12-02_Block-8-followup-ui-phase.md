# Block 8: Follow-up Tasks UI Phase Initiated — 2025-12-02

## Business Context

With the **Calendar UI Polishing (P2)** complete, the RightSidebar now has a premium, responsive foundation. The next logical step is to implement the **Follow-up Tasks UI** (Block 8).

The backend for follow-up tasks (`/api/followups/debug`) was established in Block 3 (P1), but the frontend UI is currently missing. This block will introduce a dedicated "Follow-up Tasks" widget in the RightSidebar, likely integrated with or adjacent to the Calendar widget, to display actionable items generated by agents.

## Decision

**Phase Block 8: Follow-up Tasks UI** has been initiated to:

1. **Create Follow-up Tasks Widget:** A new UI component in `RightSidebar.tsx` to display tasks.
2. **Integrate Data Layer:** Extend `useSidebarData.ts` to fetch follow-up tasks from the backend.
3. **Implement Interactions:** Allow users to mark tasks as done, dismiss them, or view details.
4. **Maintain Design Consistency:** Ensure the new widget matches the P2 polished aesthetic (Na'Vi blue, dark mode, micro-animations).

**Target Modules:**

- `RightSidebar v2.5` (Block 8)
- `FollowupWidget.tsx` (New Component)
