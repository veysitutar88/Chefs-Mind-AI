## Chef's Mind AI
An AI platform for restaurants integrating multi-agent chat, order management, financial analytics, and media generation.

## Key Components
- **Backend:** Node.js + Express + TypeScript
- **Frontend:** Next.js + React + Tailwind
- **Database:** PostgreSQL + Drizzle ORM
- **Agents:** Chef, Accountant, Researcher, Media Studio, QA-Gate
