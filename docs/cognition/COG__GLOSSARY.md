# COG__GLOSSARY.md

## UI/UX Terms

* **Unified Canon:** The agreed IDs and Labels for all AI agents.
* **Focus Mode:** Responsive behavior where sidebars are hidden to prioritize central content readability.
* **Tools Sidebar:** The widget-based Right Sidebar containing Media, Calendar, and Chats.
* **Not Connected State:** Neutral UI placeholder for features without a backend implementation.
