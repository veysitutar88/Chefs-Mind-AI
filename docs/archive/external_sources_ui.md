# EXTERNAL SOURCES — UI & ORCHESTRATOR REFERENCES

## 1. Что откуда копируем в **новый UI**

### lobe-chat
- **Сайдбар левой панели**: структура, анимация, логика активного элемента.
- **Список чатов / сессий**: компонент MessageList + SessionList.
- **Layout**: верхняя панель, область контента, паттерн переключения.

### open-webui
- **Правая панель (поиск / библиотека / календарь)**: полностью ux-паттерн.
- **Поле ввода (bottom-bar)**: кнопки микрофона, вложений, выбора модели.
- **Обработка drag‑and‑drop файлов**.

### agent-squad
- **Оркестратор намерений**: распределение запросов на агентов.
- **Классификатор intents**.

### Flowise
- **Идеи модульной структуры**: как разделять UI / агенты / workflows.
